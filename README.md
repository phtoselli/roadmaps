# 🗺️ Roadmaps

Coleção de roadmaps interativos para desenvolvimento de carreira.

Cada roadmap tem checkboxes para marcar o progresso — salvo automaticamente no navegador.

## 🗂️ Estrutura

```
├── index.html                      → Home (lista todos os roadmaps)

│   └── design/
│       ├── ux-ui/
│       │   └── index.html          → UX/UI Design (Júnior)
│       ├── product/
│       │   └── index.html          → Product Design (Júnior)
│       └── graphic/
│           └── index.html          → Design Gráfico (Júnior)

```

---

## ✦ Como usar

1. Abra o roadmap da sua área
2. Marque os tópicos conforme for estudando
3. Foque primeiro nos marcados como **essencial** — são os mais cobrados em entrevistas

O progresso é salvo automaticamente no `localStorage` do navegador.
